# SQLServer2022
This project is for the "Porte Ouverte de l'ETML", where people without any IT knowledge, will discorver the SQL server 2022 Software. The public will have an activity that is 5 to 7 minutes long to complete and have fun
## Modelisation
If you have any issues to understand how the Data Base work and how the connections between tables are made, you can check **Port_Ouverte.loo**. It will open looping which is the modelisation Software that I used. Both MCD and MLD (Merise method) can be check.
